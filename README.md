# 孕迹 PregnancyJournal

原生 Android 孕期档案应用。**本地优先、全程加密**：数据库与资料原件都用 SQLCipher / AES-GCM 保存在本机，
只有你主动配置云盘并选择上传时，加密备份才会离开设备。

> 这是个人记录工具，不提供医疗诊断或用药建议。孕周与预产期推算仅供个人整理参考。

## 特性

- **建档与孕周**：末次月经或医生确认的预产期建档，保留每次日期依据的修订历史
- **产检**：预约、取消、实际就诊记录、就诊日历、本地提醒
- **产检资料**：图片/PDF 加密导入、缩略图、全屏缩放预览、PDF 分页与放大、分类检索、损坏原件安全替换
- **用药与服药**：药品目录、方案版本历史（保留当时的药品与剂量快照）、按日服药确认/跳过/补记
- **健康指标**：体重、成组血压（可选心率）、空腹/餐后血糖、自定义指标与趋势
- **日常记录**：症状、心情、备注，以及六类来源聚合的时间线
- **提醒**：产检、用药与自定义提醒；精确闹钟不可用时自动降级；锁屏通知默认隐藏内容
- **备份与恢复**：本地加密备份（`.yunji`）、WebDAV 云端备份、代际切换式恢复、恢复前安全副本
- **导出**：结构化数据包（JSON + 原件）与就诊摘要 PDF，均为明文并需显式确认
- **安全**：系统认证应用锁、严格模式、`FLAG_SECURE` 防截屏、回收站与彻底删除

## 技术栈

Kotlin · Jetpack Compose · Room + SQLCipher · Hilt · WorkManager · OkHttp · Tink
最低 Android 8.0（API 26），目标 API 36（含 16 KiB 页设备）。

## 构建

- JDK 17 或更新版本（开发使用 JDK 23）
- Android SDK 36.1；设置 `ANDROID_HOME` 或配置不入库的 `local.properties`
- 首次构建需要访问 Google Maven、Maven Central 与 Gradle 官方下载站

```bash
./gradlew --gradle-user-home .gradle-user :app:assembleDebug :app:testDebugUnitTest
```

开发包输出到 `app/build/outputs/apk/debug/app-debug.apk`。

Windows 下还可用：

```powershell
.\scripts\verify.ps1
.\scripts\verify.ps1 -Device -Serial emulator-5580   # 仅对指定的测试设备
```

> 若使用项目本地 Gradle 用户目录（`--gradle-user-home .gradle-user`），可避免与本机全局
> Gradle 初始化脚本（镜像配置）冲突。

## 测试

### 已知限制（摘要）

- 云端备份仅支持 WebDAV（HTTPS），未与特定服务商做长期联测
- 未生成正式签名发布包；版本号与备份格式版本尚未冻结
- 部分真机/OEM 场景（厂商省电策略、锁屏通知视觉、TalkBack 全量读屏）仍待验收

完整清单见[已知限制](docs/已知限制.md)与[测试验收报告](docs/测试验收报告.md)的「未验证矩阵」。

## 安全与隐私

- 恢复密钥（`YJ1:` 开头）**不会**随备份保存，遗失后无法解密
- 云盘地址、账号与应用密码只保存在本机，由设备 Keystore 保护的密钥加密
- 应用默认 `FLAG_SECURE`，禁止系统截屏
- 仓库中不含任何真实用户数据或凭据；测试一律使用合成数据

报告安全问题时请不要在公开 Issue 中附带真实医疗数据或凭据。
