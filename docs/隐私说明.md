# 隐私说明

日期：2026-10-21。对应源码 `0.22.0-dev`。

## 1. 一句话说明

孕迹是**本机优先**的应用：你的孕期记录与资料默认只保存在这台设备上并加密存储；应用**没有运营服务器**，不会把医疗记录上传到我们或第三方的服务器。

## 2. 数据保存在哪里

| 数据 | 位置 | 保护方式 |
|---|---|---|
| 孕期档案、产检、用药、服药、健康指标、日常记录 | 应用私有目录内的数据库 | SQLCipher 全库加密；密钥由系统 Keystore 保护的设备主密钥派生 |
| 资料原件与缩略图 | 应用私有目录内的对象文件 | 逐对象 AES-256-GCM（`PJF1`），AAD 绑定资料库与对象 |
| 云盘地址、账号、应用密码 | 应用私有目录 | 以资料库主密钥派生的独立密钥加密 |
| 恢复密钥 | 仅由你保管 | 不写入应用存储；备份中只有用恢复密钥封装的主密钥 |
| 本机设置（应用锁、提醒开关、自动备份、设备角色等） | 应用私有偏好 | 不含医疗内容；仅存时间、序号、枚举与随机 ID |

卸载应用会删除上述本机数据（包括“恢复前安全副本”）。

## 3. 什么情况下数据会离开设备

只有你的主动操作：

1. **导出加密备份**（`.yunji`）：保存到你选择的系统位置；文件本身加密。
2. **导出结构化数据包 / 就诊摘要 PDF**：**明文**，保存到你选择的位置。界面上必须先确认“我了解导出内容为明文”。
3. **导出单份原件**：明文，保存到你选择的位置。
4. **云盘备份**：把**加密**对象与加密提交上传到你配置的 WebDAV 目录。
5. **分享**：通过系统分享把文件交给其他应用；分享后无法保证对方副本被撤回。

## 4. 云盘服务商能看到什么

- 加密文件的大小、数量与访问时间；
- 目录结构与随机 ID 命名的文件名（不含报告原始名称）；
- 你的账号与访问来源 IP（由服务商按其隐私政策处理）。

服务商**看不到**记录内容、原件内容与恢复密钥。

## 5. 权限用途

| 权限 | 用途 |
|---|---|
| `INTERNET` | 仅用于你配置的 WebDAV 备份 |
| `POST_NOTIFICATIONS` | 产检与服药提醒 |
| `SCHEDULE_EXACT_ALARM` | 尽量准时的提醒；未授权时降级为不精确提醒 |
| `RECEIVE_BOOT_COMPLETED` | 重启后重建提醒 |
| `USE_BIOMETRIC` / `USE_FINGERPRINT` | 应用锁与严格模式的系统认证 |
| `WAKE_LOCK` / `ACCESS_NETWORK_STATE` / `FOREGROUND_SERVICE` | 由 WorkManager 与本地存储组件合并引入，用于后台备份任务与网络条件判断 |

应用**不申请**相机、定位、通讯录、电话、短信与存储权限；拍照通过系统相机应用完成，文件选择与保存通过系统文件选择器（SAF）完成。

## 6. 网络与传输安全

- 仅接受 HTTPS，校验系统信任的证书，**不提供“忽略证书错误”选项**，不向不同源重定向携带凭据。
- 明文流量在清单层被禁用（`usesCleartextTraffic="false"`）。
- 云端“能力测试”只写入一个随机命名的临时项目并尝试清理，不会改动你已有的文件。

## 7. 诊断与日志

- 应用不写入医疗内容或凭据到日志；主源码仅一处调试日志，受 `BuildConfig.DEBUG` 保护且只记录异常类名，正式包不输出。
- 无遥测、无崩溃上报、无广告与第三方分析 SDK。

## 8. 你的控制权

- 随时在“云盘连接”中清除本机连接与凭据（云端已上传的文件不会被删除）。
- 随时删除单条记录、整份孕期或清空回收站；删除前可导出备份。
- 随时卸载应用以移除本机全部数据。

## 9. 儿童与医疗声明

本应用用于**个人记录整理**，不是医疗器械，不提供诊断或治疗建议；就诊摘要标注为“用户整理记录”，不能替代医疗机构出具的病历。
