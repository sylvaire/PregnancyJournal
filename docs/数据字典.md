# 数据字典

日期：2026-11-12。对应源码 0.26.0-dev / schema **15**。本表由 `app/schemas/cn.yunji.journal.core.database.JournalDatabase/15.json` 与实体定义直接核对生成，不凭记忆填写。

## 通用约定

- 主键：业务表均为字符串 UUID（`change_log` 为自增 `sequence`；`measurement_values` 为复合主键；`drafts` 为 `feature + draftId`）。
- 时间：`createdAt`/`updatedAt`/`recordedAt`/`effectiveAt`/`deletedAt` 等为 epoch 毫秒；日期为 `yyyy-MM-dd` 文本；时间为 `HH:mm` 文本；`zoneId` 记录当时时区。
- 回收站：`deletedAt` 非空表示在回收站；`deletionBatchId` 指向 `deletion_batches`，用于按批次恢复与清理。
- 版本：`revision` 用于编辑冲突检测；方案与指标定义用 `version` + `logicalId` 表达历史版本。
- 密文：数据库本身为 SQLCipher 加密；附件原文/缩略图为独立 `PJF1` 对象。

## 迁移

`schema 1 → 15` 全部使用 Room 自动迁移（其中 9→10 由 `MedicationIdentityMigration` 处理药品身份）。14 新增 `custom_reminders`，15 为 `prenatal_visits` 增加 `actualTime`/`actualHospital`/`actualResult`。发布路径的升级测试覆盖既有记录与草稿。schema JSON 归档在 `app/schemas/`（1–15）。
