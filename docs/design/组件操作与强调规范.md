# 组件操作与强调规范

更新：2026-11-15。适用任务：M6-VISUAL-FIX。

| 角色 | 组件 / 用法 | 视觉规则 |
|---|---|---|
| 主要提交/创建 | JournalButton默认 | 52dp起、整行主色填充，突出本页主要动作 |
| 次要整行操作 | JournalSecondaryButton，或JournalButton(secondary=true)兼容入口 | 同一描边样式，52dp起；不再一部分tonal、一部分outlined |
| 行内操作 | JournalTextAction默认 | 普通文字动作，至少48dp；多项操作空间不足时FlowRow换行 |
| 行内危险操作 | JournalTextAction(danger=true) | 警示文字与描边，不以大面积实色抢占正常操作 |
| 整行危险操作 | JournalDangerButton | 52dp起、整行警示描边；仍需原有确认弹窗 |
| 状态与筛选 | JournalTag或专用状态内容 | 选中态填充；不机械套成提交按钮 |
| 内容标题与摘要 | JournalContentHeading | 两项完整放得下时分列；放不下时标题/摘要上下排列，保留完整内容 |
| 错误与重试 | JournalError | 错误容器保持提示色；重试是普通操作，不等同删除 |

浅色交互轮廓使用outline（#91A294），装饰分隔使用outlineVariant（#DDE4DA）。不增强所有卡片边框。深色保持原角色，危险按钮自身改为描边，错误提示容器颜色不变。

首页正常孕周仍使用主要摘要；未填日期使用普通卡片和20sp标题，去掉重复状态标签。服药摘要只强调仍有待记录计划的状态，加载、无计划或全部已记录不占强调底色。

2026-11-15首页布局修订：页头将日期/档案名与问候语紧凑排列，整组可进入孕期管理；正常孕周用28sp，阶段标签邻近排列，日期完整保留，进度轨道4dp。预约与服药优先展示，四个快捷入口使用最多两列的64dp起横排卡片，按最长文字实测宽度降为一列。新建预约纳入快捷区，不再在页尾重复设置整行主按钮；没有最近资料时省去重复空卡，检查资料入口始终存在。

药品列表保留邻近操作和当前选中边框；管理区只保留一层普通卡片和紧凑操作，不重复药名或再嵌导航卡。预约操作区不恢复按钮下说明或中间分隔线，后果说明留在既有确认弹窗。

产检提醒卡片：标题/设置状态分列；日期和时刻分列，时刻用28sp，空间不足整组换行。未设置时使用统一全宽描边设置按钮；已设置时修改为主色文字、关闭为次级文字，操作区可换行。时区、通知及锁屏说明保留在设置弹窗，不堆在卡片底部。时间输入用短标签“提醒时间”和字段辅助文字“24小时制”，避免大字浮动标签换行侵占上一字段。

全卡片统一修订：普通空态与未开启/未确认状态使用中性底色；关键步骤、已确认状态及待处理摘要按角色强调。失败卡片不使用绿色成功强调。设置项使用JournalSettingRow，文字可换行，开关保留完整宽度和16dp间隔；不可打开详情的静态说明完整显示。键值短内容两端分列，长内容上下排列，不重复设置数值尾对齐。卡片内多项操作必须换行或使用全宽主次排列；不恢复取消/删除之间的说明或分隔线。备份最近结果、进度、取消与上传集中在同一卡片，避免重复状态卡。
