# 语义图标规范与替换清单

更新：2026-11-13。用于修复 UI/UX 审计发现的「图标语义错配」问题。

## 1. 背景

审计发现 `app/src/main/assets/design/` 只有 **14 个 SVG**，而 `RecordRow` 被用于几十个功能，
图标被迫反复复用，导致明显错配（如「全局回收站」配禁止符号、「安全设置」配叶片）。

## 2. 设计规格（沿用现有图标）

从现有 SVG 提取的统一规格，新增图标必须完全一致：

| 项 | 值 |
|---|---|
| 画布 | `24 × 24`，`viewBox="0 0 24 24"` |
| 描边宽度 | `1.7`（导航类）/ `1.75`（操作类） |
| 线帽/连接 | `stroke-linecap="round"` `stroke-linejoin="round"` |
| 主色 | `#356B53`（`Primary`） |
| 填充 | `fill="none"`（纯描边风格） |
| 根元素 | 与 `cdc29.svg` 一致：`preserveAspectRatio="none" overflow="visible" style="display: block;"` |
| 安全边距 | 图形限制在 `3..21` 区间内（2px 留白） |

## 3. Ardot 侧约定

**当前状态**：Ardot MCP `https://ardot.tencent.com/mcp` 返回 **401**（需认证），网页端访问超时，
本机未配置 Ardot 凭据。因此本轮图标按上述规格在本地绘制，**Ardot 恢复后可直接平替**。

替换方式：把 Ardot 导出的 SVG 覆盖同名文件即可，代码侧无需改动。

设计文件与节点索引见 [ardot-state.json](ardot-state.json)。补充图标建议放入 Ardot
「图标 / Icons」独立页面（`node_id` 待定），与 N01–N22 画板并列，便于统一导出。

## 4. 新增图标清单

命名规则：`<语义>.svg`，与功能语义一一对应。旧的无语义哈希文件名保留（避免破坏现有引用），
新代码优先使用语义化文件名。

| 文件名 | 语义 | 用于 |
|---|---|---|
| `ic-trash.svg` | 回收站 | 全局回收站、删除药品、删除孕期 |

## 6. 验收

- 每个新增 SVG 可通过 `coil` 的 `SvgDecoder` 正常渲染（无 XML 错误）
- 在 `24dp` 尺寸下线条清晰、无视觉重量差异
- 深浅色主题下 `colorFilter` 着色正常（SVG 内 `stroke` 会被 tint 覆盖）
- 截图核对：同一页面内相邻图标语义可区分
