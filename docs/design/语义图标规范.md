# 语义图标规范与替换清单

更新：2026-11-13（第二轮：Ardot 设计稿同步）

## 1. 背景

审计发现 `app/src/main/assets/design/` 只有 **14 个 SVG**，而 `RecordRow` 被用于几十个功能，
图标被迫反复复用，导致明显错配（如「全局回收站」配禁止符号、「安全设置」配叶片）。

第二轮补齐后：**Ardot 设计稿与代码侧已完全对齐**，两侧均为同一套 16 个语义图标 + 10 个基础图标。

## 2. 设计规格（唯一标准）

| 项 | 值 |
|---|---|
| 画布 | `24 × 24`，`viewBox="0 0 24 24"` |
| 描边宽度 | `1.75`（全部图标统一，无例外） |
| 线帽/连接 | `stroke-linecap="round"` `stroke-linejoin="round"` |
| 主色 | `#356B53`（Ardot 变量 `孕迹 · Light / primitive/primary`） |
| 填充 | `fill="none"`（纯描边风格） |
| 根元素 | `preserveAspectRatio="none" overflow="visible" style="display: block;"` |
| 安全边距 | 图形限制在 `3..21` 区间内（实测 2.1–21.9） |

**第二轮修正**：首轮本地图标混用 `1.5 / 1.6 / 1.7 / 1.75` 四种描边，与设计稿的 `1.75` 不一致。
现已把全部 20 个 `ic-*.svg` 归一到 `1.75`（`ic-check.svg` 原本即是 1.75，未变）。

### 3.2 踩坑记录（避免重复）

1. **SVG 导入会把描边转成填充**，而且内层 `Frame` 被定位到 `x=-12, y=-12`，导致渲染被裁成一个角。
   必须插入后用 `U("<frameId>", {x: 0, y: 0})` 修正，并 `U("<componentId>", {fills: []})` 清掉白色底。
2. **`vectorPaths` 不支持写入**：`set_vectorPaths: (void 0) is not a function`。只能走 SVG 导入。
3. **`description` 写入恒失败**：`set_description: DOMParser is not defined`（Ardot 服务端缺陷），
   因此组件描述未写入，语义靠**命名**表达。
4. **变量 ID 不能直接当引用**：`stroke: "$7:18"` 报 "not a COLOR variable"（`color/primary` 是别名）。
   必须用 `$:孕迹 · Light:primitive/primary`（或 `$7:7`）。
5. `batch_edit` 的 `operations` 是**单个字符串**（换行分隔），不是数组。
6. 节点数一多 `batch_read` 会转存成 JSONL 下载链接，需逐节点读取。

## 4. 风格一致性核验（10x PNG 像素测量）

对 27 个图标导出 10 倍 PNG，统计不透明像素占比、包围盒与主色：

| 指标 | 原有 10 个 | 新增 17 个 | 结论 |
|---|---|---|---|
| 墨迹占比 | 6.5–27.0%（均值 17.2） | 11.6–28.3%（均值 19.1） | 同一量级 |
| x 包围盒 | 2.1–21.9 | 2.1–21.9 | 完全一致 |
| y 包围盒 | 2.1–21.9 | 2.1–21.9 | 完全一致 |
| 主色 | `#356B53` | `#356B53` | 完全一致 |
| 描边 | 1.75 ROUND/ROUND | 1.75 ROUND/ROUND | 完全一致 |

低墨迹的 `check`(6.9%)、`chevron`(6.5%) 是单线条形状，属正常；新图标无对应形状，故区间偏窄。
