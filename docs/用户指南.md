# 用户指南

日期：2026-11-12。对应源码 `0.26.0-dev`。本指南描述**已实现并验证到隔离环境**的功能；未验证项见[已知限制](已知限制.md)。

孕迹是一款**本机优先**的孕期记录应用：记录默认只保存在这台设备上，数据库与资料原件均加密存储。只有当你主动配置云盘并选择上传时，加密备份才会离开设备。

## 1. 开始使用

1. 首次打开应用会创建本机加密资料库（密钥由系统 Keystore 保护）。若设备启用了应用锁/严格模式，打开前需要系统认证。
2. 建档：**我的 → 管理孕期**，填写名称、末次月经或预产期、医院与备注。预产期与孕周会据此推算，日期依据的每次变化都会留下历史。
3. 四个一级入口：**今天 / 产检 / 记录 / 我的**。

## 2. 日常记录

- **产检**：新建预约（日期、时间、医院、检查项目、准备事项），就诊后填写实际日期与医生建议；可设置本地提醒；可指定本次产检的封面资料。
- **记录 → 日常记录**：备注、症状、心情；支持编辑草稿、修改历史与回收站。
- **资料**：拍照或从系统选择图片/PDF 导入，导入后自动加密；可预览（图片缩放、PDF 分页/跳页/放大）、重命名、分类、设置报告日期/医院/备注、按名称或备注搜索。原件损坏时可安全替换，也可导出单份原件。
- **用药方案 / 服药记录**：药品录入与复用；方案支持每日/每周/一次/按需/原文；修改保留版本历史，并保留录入当时的药品名称与规格快照。服药记录支持确认、跳过、补记、修改实际剂量与时间；重复提交不会产生重复记录。
- **健康指标**：体重、成组血压（可选心率）、空腹/餐后血糖与自定义指标；支持精确数值、场景与餐后分钟、趋势与详情。

## 3. 删除与回收站

删除的项目先进入**回收站**（我的 → 全局回收站），可在保留期内恢复。孕期整体删除会产生一个批次，恢复时按批次恢复。仍在被引用的药品不能单独彻底清理，会保留到所属孕期整体清理。

## 4. 备份（重要）

### 4.1 保存恢复密钥

**我的 → 本地备份**：生成恢复密钥并完整抄录（含 `YJ1:` 前缀、区分大小写），然后按提示核对其中两组。**完整密钥只显示一次**，请与备份分开保管。

### 4.2 导出加密备份

同一页面选择“导出加密备份”，把 `.yunji` 文件保存到你选择的位置。导出前会校验数据，导出后可离开设备保存。

如果导出中断、应用重启后提示重新选择位置，或提示系统无法删除不完整文件，请到刚才选择的保存位置查看：**删除本次创建的文件（如仍存在）并新建文件重新导出**。不要把未显示“已保存并通过校验”的文件当作可用备份；本机原资料不会因导出失败而删除。

### 4.3 云盘备份（可选）

**我的 → 云盘连接**：填写 WebDAV 的 HTTPS 地址、账号与应用密码，选择备份父目录，然后“测试并保存”。只有通过写入与回读校验的连接才允许上传。

**我的 → 云盘连接 → 云端备份**：
- “立即上传备份”会先在本地制作并自检加密快照，再逐项上传、回读校验，最后发布认证提交；**只有提交回读通过才记为成功**。
- 自动备份默认关闭。开启后，本机修改会在短暂合并后触发一次唯一备份任务；失败按指数退避重试。
- 恢复或更换设备后，本机默认**不是主设备**，需要你点“将此设备设为主设备”才会自动上传。
- 若在云端发现其他设备提交的备份，自动备份与自动清理会暂停，需你确认主设备。
- 云端只保留最近 7 天每日一份与最近 4 周每周一份，并始终保留最近完整快照；被保留快照引用的对象不会被删除。

## 5. 恢复资料

**我的 → 本地备份 → 从备份恢复资料**：

1. 选择 `.yunji` 备份文件；
2. 输入该备份对应的恢复密钥；
3. 等待校验，查看预览（孕期/产检/资料/方案/服药/测量/记录数量与来源）；
4. 勾选确认后开始替换。

恢复会**整体替换**当前记录（不合并）。替换前会自动为当前资料生成“恢复前安全副本”，可在同页面看到并导出。恢复完成后需要重新打开应用载入新资料；自动云端备份保持关闭，请核对资料后再确认主设备。

**恢复前安全副本**需要**当时**对应的恢复密钥才能打开，可能与你现在的密钥不同，请连密钥一起保存。

## 6. 导出资料（明文）

**我的 → 导出资料**：

- **结构化数据包（.zip）**：字段说明、来源索引、各业务表的 UTF-8 JSON 数组与原件；空值写为 `null`，与空字符串不同；包内 README 会说明不包含的内容（草稿、云盘凭据、恢复密钥等）。
- **就诊摘要 PDF**：范围、生成时间与“用户整理记录、不是医疗机构出具的记录”标记；缺失字段显示“未填写”，长备注不截断并自动分页。

两者都是**明文**，需要先勾选“我了解导出内容为明文，将自行妥善保管”才能开始；保存位置由系统文件选择器决定，目标必须为空文件。

## 7. 隐私与安全要点

- 记录与原件加密保存在本机；应用内可开启应用锁与严格模式（**我的 → 安全设置**），支持立即锁定与超时自动锁定。
- 锁屏通知默认隐藏具体内容。
- 云盘密码以本机密钥加密保存，不会因更换服务或账号而发送到新地址。
- 详细说明见[隐私说明](隐私说明.md)。
