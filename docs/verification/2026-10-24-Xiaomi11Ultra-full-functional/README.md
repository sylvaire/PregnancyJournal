## 方法与限制

- MIUI 拦截仪器测试进程启动 Activity，因此真机只能 **adb 驱动 UI**（`am start` + input + uiautomator dump），或运行 **非 UI 的 androidTest**（数据/加密/网络类，不启动 Activity）。
- 应用 `MainActivity` 设置了 `FLAG_SECURE`（`MainActivity.kt:85`），**应用内容无法通过 adb 截图**（返回空文件）；系统 UI（通知栏、设置页等）可截图。UI 视觉对齐改用模拟器 Compose 截图（`captureToImage`）。
- 合成数据用于全部验证；结束前清理或注明保留原因。

### 设备侧限制：11 Ultra 无法安装 instrumentation 测试 APK
- 尝试在 11 Ultra 安装 `app-debug-androidTest.apk`（小米 11 Ultra / MIUI 14）失败：`INSTALL_FAILED_USER_RESTRICTED: Install canceled by user`；`adb shell pm install` 同样失败。应用 APK 可正常安装，判断为 MIUI 对 instrumentation/test 包的限制（另：`testOnly` 已用 `-Pandroid.injected.testOnly=false` 去掉，仍被拦截）。
- 因此云盘/备份恢复相关**非 UI 设备测试**改在专用 API36 模拟器运行（见下）；11 Ultra 侧的上传/云端恢复只能通过真实 UI（需真实 WebDAV 服务与凭据）或后续用户协助解除限制。
