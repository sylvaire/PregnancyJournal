## 覆盖内容

- 结构化数据包：ZIP 内含 README（明文与范围提示）、fields.json（字段说明）、sources.json（来源索引）、`data/<表>.json`（UTF-8 JSON 数组）、`originals/<对象>`（原件）与最后写入的 manifest.json（计数、对象清单、包内清单）。空值写为 JSON null，与空字符串区分；只导出字段字典中登记的键，未登记列不会泄漏；原件流式复制并计算 SHA-256，与预期不符即中止；检查点支持取消。
- 字段字典：覆盖全部13个业务段，逐字段给出中文名、类型与内部索引标记，并显式列出不导出内容（草稿、导入来源URI、云盘凭据、恢复密钥与设备封装、本机设置、提醒调度标识）。
- 就诊摘要：范围、生成时间与“用户整理记录、不是医疗机构出具的记录”标记落在首页；孕期信息、产检、用药（含服药统计与明细）、选定指标分组呈现；缺失值显示“未填写”；长备注不截断，跨页续排并带续页页眉；节标题不与内容分离。
- 真实 PDF：用 Android PdfDocument 生成 A4 多页文档；PdfRenderer 复核页数与渲染结果完全一致、逐页非空白、超长备注确实分页，且同一摘要两次生成页数一致。
- SAF 目的地：目标必须为空（非空目标报错且保留用户文件）；写入后**通过提供方回读**校验：PDF 校验 `%PDF-` 头与 `%%EOF` 尾且大小合理，结构化包重新打开 ZIP 并确认 manifest 可解析；导出不申请持久授权，并在结束时释放可能残留的授权。
