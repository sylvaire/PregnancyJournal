## 覆盖内容

- schema 10 为方案版本新增药品名称/规格/剂型快照；9→10迁移先从原药品回填，再允许编辑。药品基础信息编辑只改当前药品，不覆写已保存方案版本；旧编辑使用revision拒绝，方案保存校验药品revision，旧编辑不会覆盖新信息。
- 包装照片复用加密导入、缩略图、预览、元数据、回收站与清理链路；attachments/import_jobs以medicationId作为唯一所有者，只接受图片，分类固定为PACKAGE，删除药品时按同一批次软删除，恢复后缩略图与预览可用。
- 药品独立批次覆盖本药品、全部方案版本、服药点/记录及包装照片；恢复不复活此前单独删除项。仍有方案引用（包括已随药品删除的方案）时禁止独立彻底清理，到期维护跳过，随孕期整体清理。
- 药品历史显示“当前药品信息”与每版快照，生效时刻按该版本录入时区展示；时间线将包装照片归入药品来源。
