## 覆盖内容

- 数据提取：DAO 读取13个业务段，按日期范围、回收站开关与区段选择过滤；测量日期按其自身时区换算后再过滤。
- 一致性：原件采用“选中对象租约”，在写入事务内一次性捕获关联行与对象并 pin，随后释放事务再做较慢的加解密与网络/提供方 IO；导出过程中相关记录的原子编辑会被等待，不会被撕裂。
- 明文确认：未勾选“我了解导出内容为明文”时两个导出按钮都不可用，也不会打开系统选择器；日期范围非法（含不可能的日历日期）同样阻止开始。
- SAF 交接：新增 `EXPORT_DATA`/`SUMMARY_PDF` 两种请求，向导选项以 JSON 载荷随交接保存（不含凭据或医疗值），写入前有防重放保护，导出为一次性写入。
- 回收站策略：勾选“包含回收站记录”时，回收站附件只导出**记录信息**，其明文原件不导出（导入器本身拒绝回收站原件），且结果中明确说明“回收站原件 N 份未包含”，不静默少给。
- 界面：新增“我的→导出资料”，含日期范围、区段勾选、是否含原件/回收站、统计当前范围、明文确认与两个导出按钮、进度与取消、结果与错误提示。
