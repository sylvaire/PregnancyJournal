- TLS+附件组合：DavBackupRemote 与 CloudBackupUpload 在真实TLS链路上完成目录准备、逐项不可变上传、回读校验、提交发布与回读，重试不重写已校验对象与提交。
- 身份与防篡改：跨库恢复封装被拒绝且不写远端；云端已有损坏密文时停止而不覆盖；缺少本地源文件在首个网络请求前失败；提交回读缺失或不可读不产生成功回执；不受信证书不被忽略。
- 顺序规则（CloudBackupPipeline）：先持久预留writer序号，再生成清单/归档并本地自检，最后才上传；序号与快照不一致、恢复封装跨库、原件缺失或密文校验失败均在接触网络前终止；失败消耗序号不回收。
- 状态：CloudUploadStatusStore 记录最近尝试/最近成功/快照ID/序号/阶段/错误，仅设备本地、无医疗内容与凭据；界面区分“尚未成功”和“上次未完成”，并要求连接已通过写入回读校验才允许上传。
