# D02 恢复封装与密钥片段核对组件

2026-10-19。最终debug构建、67项JVM测试通过，lint0错误/20警告。新增RecoverySlotTest三项、RecoveryKeySetupTest两项；原始证据见build.log与两个XML。本轮无新增设备测试、未安装手机。此前生命周期31项模拟器证据仍单独保留，不冒充本轮设备验证。

RecoverySlots独立于P0三表探针。随机256位YJ1恢复密钥经独立用途HKDF-SHA256派生恢复封装密钥，AES256-GCM封装VMK；AAD绑定vaultId、随机slotId和算法。公开描述仅格式/标识/算法/封装密文，没有原始恢复密钥、主密钥或医疗内容。对封装大小、标识、算法、密文长度和UTF8设边界；不开放口令或伪KDF。派生密钥和解析出的临时密钥字节finally清空，返回VMK由恢复会话负责擦除。

RecoveryKeySetup仅内存持有原始密钥字节，不可序列化，toString脱敏。八组每组六字符，随机要求两个不同组；错误答案不产生恢复槽，正确核对后生成恢复槽并清空临时字节，取消同样作废且不再提供keyText。此组件尚未接入UI；UI必须在核对页隐藏完整密钥、不把它放入保存状态/日志/偏好，锁定/离开时关闭setup。

测试覆盖正确密钥恢复、错误密钥、vaultId/slotId替换、密文篡改、新槽独立标识/密文、不支持算法/版本、超大输入、无效UTF8/路径标识、双片段错误/成功及取消作废。不是完整归档/独立恢复验收；格式候选尚需与vault.json/归档协议整体验证后冻结。
