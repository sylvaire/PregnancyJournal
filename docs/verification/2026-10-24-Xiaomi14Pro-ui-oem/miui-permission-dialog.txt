# MIUI notification permission dialog (user 11)

Triggered by tapping the app's own 开启通知权限 button on the reminder settings page.

Activity: com.android.permissioncontroller/com.android.permissioncontroller.permission.ui.GrantPermissionsActivity

Dialog text observed:
- 允许“孕迹”发送通知？
- 包括消息推送、桌面图标角标、声音和振动提醒等，可在“设置”中修改。
- Buttons: 拒绝 | 始终允许   (AOSP wording is usually 不允许/允许; MIUI uses 拒绝/始终允许)

After tapping 始终允许:
- Reminder settings page shows 已允许显示通知 and the 发送测试通知 button.
- Notification record was posted successfully (see notification-record.txt).
