## 已实现

“我的→云盘连接”，HTTPS地址/账号/应用密码、手动或逐级浏览选择父目录；浏览仅读取，确认后才修改表单。测试和保存分离，输入变化使旧测试失效；已保存密码不回填，空密码仅可沿用同一规范化端点和账号，换服务或账号必须重输。

连接、测试清理标记与限流状态以VMK派生密钥/AAD分用途加密，放在noBackup目录，不进入明文偏好、导航参数、SavedStateHandle或正式备份。离页/失去前台取消在途响应并清空未保存密码，严格模式资料密钥不可用时不继续打开配置。

探测分开验证端点、目录读取、随机目录创建、随机256字节写入/下载回读、可选HEAD、删除；只读不能误报可备份。发现专用目录和候选资料库目录，但不把目录名当作已验证的备份身份。所有写入只在随机测试路径，已有资料不改动。

中断/清理失败保留不含密码的加密标记；同端点/账号/目录重试先处理旧标记，确认随机测试目录为空才删除。用户可以经明确确认清除本机标记，界面说明云端遗留需自行核对。

401/403/404/405/409/413/507/429各自提示；Retry-After秒数和HTTP-date均解析，等待期限加密持久化，同源等待期内拒绝再次联网。等待最多7天；没有有效值的429采用30秒等待。401/429/带限流503不在finally中继续发清理请求，保留标记供后续恢复。
