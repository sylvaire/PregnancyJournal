## 覆盖内容

- schema12为产检增加`reminderDate`/`reminderTime`，schema1–11升级到12保留原资料、药品、日常记录、回收站和封面/对象指针。
- 产检提醒使用本地墙钟日期/时间；无具体预约时间时由用户选择提醒时刻，不假设午夜。用药提醒从当前有效方案生成未来7天服药点，已记录（含跳过）的点不提醒，暂停/结束/删除方案和已结束孕期不提醒。
- 7天投影在应用启动、每日维护、规则变化、重启/时间/时区/日期变化和通知动作后重建；generation递增并用AlarmManager取消旧事件，旧回调用generation屏蔽。
- 精确提醒能力检查：有权限时使用`setExactAndAllowWhileIdle`，无权限/未授权时降级`setAndAllowWhileIdle`；设置页显示当前模式并解释系统可能推迟。
- 通知渠道“孕迹提醒”锁屏可见性PRIVATE，并提供公共版本（仅“孕迹提醒”和待确认提示）；通知正文可含产检/药品摘要，但不在锁屏公开。无通知权限时不发送，应用内页面继续提供待办。
- 用药通知提供“已服用”和“稍后10分钟”。已服用使用服药点ID幂等写入实际记录并重建；稍后提醒只保存一次性延后时间并重排同一事件，不改变原计划服药点。通知动作在generation失效或业务状态变化时拒绝。
- Boot/包更新/时间/时区/日期广播触发重建；进程内前台动作和离开应用也排入唯一重建任务。系统强行停止或厂商后台限制仍可能导致不送达，设置页明确说明。
- 通知投递测试通过真实AlarmManager→BroadcastReceiver→NotificationManager链路，验证标题、PRIVATE可见性与渠道；调试构建使用仅限TEST target的测试钩子，发布构建不启用。
