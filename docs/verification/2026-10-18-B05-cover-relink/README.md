## 覆盖内容

- schema11为附件增加不可变密文对象指针`objectId`，为产检增加`coverAttachmentId`；schema1–10升级到11保留旧资料、药品方案、回收站、日常记录与健康数据，旧附件没有指针时继续以附件ID读取。
- 封面：同一产检的READY资料可设为封面，列表显示标记；取消、单份删除、彻底清理或重新关联后清理失效封面，恢复不伪造封面。视为该次产检的代表资料；一份资料包含多文件的分组与顺序调整仍未实现。
- 重新关联：只允许同一孕期内移动到未删除产检，同步附件与导入任务归属；原产检封面自动清除。原产检已删除的保留资料可从全局回收站重新关联，不改变原件、名称、分类和备注；跨孕期和包装照片被拒绝。
- 损坏原件替换：读取新来源并校验文件头/大小/空间，写入新密文对象并完成GCM认证后才切换附件指针；名称、分类、报告日期、备注、封面和所属产检保留，旧对象与旧缩略图清理，缩略图失败不破坏原件。替换不覆盖旧文件，失败时旧原件仍可读。
- 原件导出：预览和资料卡提供SAF导出；先解密到私有临时文件并通过完整性校验，成功后才写入用户选择位置，结束后删除临时明文。单份导出不吞并D07结构化导出和摘要PDF。
- 极限边界：3600×2400 JPEG导入后缩略图最长边≤512；20页1200×1600 PDF逐页渲染，单页≤400万像素，关闭预览后临时明文删除；损坏原件的认证失败不让预览暴露内容。

仍保留：真实相机/系统图片与PDF提供方、权限失效、超大文件/低空间/低内存真机矩阵，图片旋转与分享，PDF密码输入，一份资料多文件分组/排序，OCR；以及C05/C06、D/E和旧预约动画问题。E01最终矩阵复核时不把本轮结果当作完整B05或V1.0验收。
