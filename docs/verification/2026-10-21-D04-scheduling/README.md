## 覆盖内容

- 唯一任务：所有自动与手动上传共用同一个唯一 WorkManager 名称，触发采用替换语义，编辑突发只保留最新一次请求；Worker 进入前再用任务级运行标记拦截并发，运行中再次触发返回重试而不是并行上传。
- 合并与周期：本地编辑后延迟30秒合并触发；周期补偿设为6小时且遵循系统调度，不承诺固定时刻；仅 Wi-Fi 为默认约束，用户可关闭。
- 主设备规则：自动备份默认关闭且需明确开启；非主设备即使开启也不会自动上传；恢复或更换设备后默认非主设备，需用户显式“设为主设备”。
- 多 writer：上传前枚举目标目录的提交；若存在本机最近成功快照之外的提交，则暂停自动备份并记录原因，只有用户确认主设备才清除该阻断。协议仍按 writer 分支保全快照，不宣称强制排他。
- 重试：失败按指数退避（60秒起、上限6小时）并持久化下次尝试时间；连续失败达阈值后停止自动重试并提示手动处理；成功清空失败计数并记录已备份的 capturedSequence。
- 待备份判定：以 capturedSequence 与上次成功值的比较为准，没有新记录时不触发上传。
