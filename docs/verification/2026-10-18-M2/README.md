日期：2026-10-18，上海时区。对应[M2阶段记录](../../阶段记录/M2-产检资料与导航体验.md)。这是M2首个增量，资料导入、预览、关联和回收站仍待后续开发。

## 交付内容

- 管理孕期独立下级路由；预约、编辑、实际就诊、管理、日期历史均有固定顶部返回按钮。
- 下级整页进入/反向返回；根入口淡入淡出，保持各自的筛选与列表状态；返回不通过突然增减父容器留白实现。
- 日历跨月、日期筛选、状态筛选；取消/恢复预约；实际就诊日期和备注独立保存；时间可留空。
- 结束后归档/移出归档、日期依据历史；同毫秒修订顺序稳定。
- 预约与实际就诊草稿隔离，新预约按孕期隔离；旧版草稿迁移不覆盖已存在的新草稿。

## 可复现命令

专用模拟器启动、依赖缓存齐备时，在项目根目录运行：

```powershell
.\scripts\verify.ps1 -UseInstalledGradle -Offline -Device -Serial emulator-5580
```

联网首次构建去掉Offline。真机必须解锁并在UI测试期间保持亮屏；用真实的测试设备序列替换Serial，不将序列、配对码写进文档。
