## 改动

- 预约详情底部新增“记录管理”卡片。取消预约为全宽次要按钮，说明记录与资料保留、之后可恢复；删除产检记录为独立全宽警示按钮，以分隔线及说明区分两种后果。
- 药品管理的删除操作改为同规格的全宽警示按钮。
- 共用行内危险操作从裸文字改为错误色描边按钮，覆盖服药、测量、提醒、方案结束、资料、备份、回收站和清除连接等现有调用；触摸目标至少48dp，按钮随文字增长。
- 测量和提醒行内操作改为FlowRow，空间不足时换行。保留原有确认弹窗、回调、禁用态及数据处理。
