# N12 全局回收站对齐（2026-10-26）

## 设计与范围

- 对照 Ardot 文件 `737849992357132` 的 N12-final 画板；设计是紧凑项目行和独立操作说明。
- 本轮只修改 App 与模拟器测试，不修改 Ardot 画板；使用独立合成资料，未安装小米 11 Ultra。

## 完成内容

- 已删除的孕期、产检、药品等批次默认显示为紧凑项目行，包含类型和删除日期；点开后显示完整影响范围、恢复条件以及恢复/彻底删除操作。原有权限与确认条件未放宽。
- “删除的项目”分组标题置于列表上方，30 天保留及云端备份说明移至列表末尾。搜索后打开项目会清除输入焦点并收起键盘，避免遮挡操作。
- 彻底删除确认框增加稳定测试标记；最终确认按钮改用危险操作色。只验证打开和取消，没有执行永久删除。
- 单独删除的资料与产检删除后保留的资料也改为紧凑行，点开后分别显示恢复/彻底删除或预览/重新关联/删除；保留资料说明移到列表之后。
