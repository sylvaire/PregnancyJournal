## 真机性能测量

同一小米设备、同一非debug性能包；允许R8方法体优化，保留跨APK测试入口/名称，所以不等同于完整release裁剪/混淆。旧实现保存于androidTest的LegacyDocumentImporter/LegacyEncryptedFileStore，使用相同临时schema3测试库，重放0.3.0导入/流代码；不是在用户库回滚安装旧版。固定随机种子生成JPEG，不包含医疗内容。

每个场景5次单图、5次双图批次。计时从直接调用处理器开始，包含原件归档、认证与缩略图结束；不包含选文件、文件提供方远程下载或WorkManager调度等待。总耗时不能当作纯AES性能。各次数据含首次调用，不丢弃较慢样本。

| 场景 | 单文件大小 | 中位数 | 最慢值 |
|---|---|---|---|
| 旧实现，小图单张 | 81,819字节，256×384 | 534ms | 562ms |
| 新实现，小图单张 | 相同 | 27ms | 34ms |
| 旧实现，小图两张批次 | 每张相同 | 1050ms | 1065ms |
| 新实现，小图两张批次 | 每张相同 | 53ms | 62ms |
| 新实现，大图单张 | 5,183,211字节，2048×3072 | 109ms | 129ms |
| 新实现，大图两张批次 | 每张相同 | 198ms | 207ms |

证据：[性能摘要](性能摘要.json)、[小图旧实现](before-small.json)、[小图新实现](after-small.json)、[最终大图新实现](after-final-large.json)，对应3次真机JUnit计时用例均通过。[大图执行输出](真机大图测量.txt)、[小图旧执行输出](真机小图修复前.txt)、[小图新执行输出](真机小图修复后.txt)。

[阶段A大图数据](阶段A大图批量写盘修复后.json)为增加快速空间检查前的中间结果，首次总耗时2598ms；不能混作最终版本数据。旧实现大图测量长时间未产出完整样本，已停止，**不计算大图提速倍数**。小图的改善比例不外推到所有真实报告。

优化包括：修正不关闭流包装器的逐字节写盘，批量GCM解密，预览不再等待整批导入长锁，前台即刻尝试处理并以持久Worker备援，空间充足时避免逐张查询可回收缓存；认证、哈希、大小校验和原件格式保留。
