# D07 导出范围与交接设置保护

日期：2026-10-21。源码版本仍为0.21.0-dev，本轮未发布新版本，未安装个人手机。

## 完成及验证

- 原件准备仅使用筛选后的附件；附件所属孕期、产检、用药的删除状态及相关日期纳入范围判断。
- 来源索引仅来自实际导出的孕期和产检区段，避免未选元数据进入数据包。
- 健康测量按记录时区的当地日期过滤，测量值随选中的测量记录导出。
- SAF交接的导出设置必须完整、字段已知且日期/区段有效；损坏、缺失或未知类型均拒绝，不再回退为全量导出。Activity在标记交接开始前校验，控制器另行防御并提示重新选择。
- debug及测试APK构建成功；222项JVM测试通过；专用API34模拟器24项通过（Service 8、Controller 8、UI 4、SAF 4），14.227秒。见build.log和device-tests.log。
- Controller回归覆盖空设置、非JSON、空对象、非法日期、未知字段、未知类型均不调用导出，以及有效设置恢复后保留仅产检且不含原件的选择。

## 未完成

现有UI/数据库接线已通过上述隔离测试，但尚未完成实际MainActivity→系统选择器往返、生命周期完整矩阵和导出快照一致性。多次数据库读取与原件读取期间的并发变更/撤销仍需审核；不据此宣称D07、M4或V1.0完整验收。
