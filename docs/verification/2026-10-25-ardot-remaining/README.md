- N05 日期依据历史：加入真实类型筛选、名称/日期搜索、修订详情展开，记录按生效时间逆序。

- N22 产检资料：加入图片、PDF、回收站标签，搜索与筛选保持可见；缩略图改为 56dp 行内展示。导入、预览、替换、分享、删除等原有能力保留。
- N12 全局回收站：增加全部/孕期/产检/资料分类和名称搜索，保留“删除的项目/保留的资料”两种真实状态及恢复条件、彻底删除确认。
- N15 服药记录：历史页增加“仅看补记”和按日期/药品搜索，按日计划与已有编辑、删除、撤销流程保留。
- N19 服药补记：备注与说明单独成组，保存操作移至说明之后；补记只能记录实际已服用，跳过仍须从对应计划项进入。
- N20 产检月历：日历态改用独立标题，将状态筛选放到月历之前、预约行紧接月历，新建入口移至结果后方。保留真实星期排列与可点选日期。

## 视觉结论与遗留

- N04/N05 层级和色彩接近画板；N16 层级接近，但字段缺失需按产品模型单独设计。
- N22 列表缩略图明显收紧，操作区仍比画板密集；N12 分类/搜索与画板一致，真实项目卡保留风险说明与操作按钮，因此比演示画板更高。两页只能标记为局部对齐。
- N15 历史卡仍比画板高；N19 表单现有数据字段与设计示意不同，首部方案信息和字段顺序仍需处理。
- N20 画板最终稿中十月日期列序有误；App 依真实星期排列。N21 设计是静态说明卡，真实原件需要全屏显示与手势操作，尚需新版图片/PDF 两种截图对照。
- N06/N07、N08–N11、N17/N18/N21 和 N22 的剩余状态仍需逐屏对照；大字体、深色、真机视觉尚未完成。
