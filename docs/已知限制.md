# 已知限制

日期：2026-11-12。对应源码 `0.26.0-dev` / versionCode27 / schema15。
本文件面向使用与验收，列出**当前版本确实存在**的限制。未列入的“未验证项”见[测试验收报告](测试验收报告.md)。

## 1. 数据与恢复

- **恢复会整体替换**当前资料，不合并；恢复前自动生成“恢复前安全副本”，卸载应用会一并移除该副本。
- 恢复后**默认不是主设备**且自动云端备份关闭，需要你明确选择主设备才会自动上传。
- 恢复支持本地 `.yunji` 加密备份与**云端最新快照下载**（生产适配→暂存解密校验→预览→提交）；未与真实服务商联测（见第 2 节）。
- 恢复密钥遗失且设备丢失时，备份无法解密。恢复密钥与本机应用锁不同，且不会随备份明文保存。
- 恢复后旧代际保留供回退；恢复页面已提供“回收旧代际”入口（二次确认、指针/日志校验后删除）。设备端定向已验证（真实加密库回收→再次恢复链路）；真实断电与大代际删除性能尚未验证。

## 2. 备份与云端

- 云端支持范围为 WebDAV（HTTPS）；**未与具体服务商联测**，实际配额、限流、`DELETE`/`last-modified` 行为可能不同。
- 不假设服务端支持 ETag、断点续传或原子 MOVE；上传为大文件时依赖单次 PUT 完成。
- 检测到其他设备提交时会暂停本机自动备份与自动清理，但**协议不做跨设备强制排他**；网络分区下不能保证即时发现双主。
- 远端清理只在“上传成功后且距上次清理满 24 小时”自动触发；云端设置页提供「云端清理」小节可查看上次清理时间/结果/计数并手动执行（二次确认）。长期不上传的设备仍需手动触发。手动与自动共用同一实现，UI 与 runner 之间为进程内互斥，**不是跨进程硬锁**。
- 服务端不返回 `last-modified` 时对象年龄视为未知，这类孤立对象不会被自动删除（保守，可能长期占用空间）。
- 云端可见的仍是加密文件的大小、数量与访问时间，服务商能看到这些元数据。

## 3. 导出

- 结构化数据包与就诊摘要 PDF **均为明文**；导出后不受本应用保护，请自行妥善保管。
- 勾选“包含回收站记录”时，回收站附件**只导出记录信息**，其明文原件不导出（结果为安全策略，界面上会说明份数）。
- **单份原件分享**：通过临时 FileProvider URI 分享单份原件，只授予只读权限且仅开放分享目录，返回页面后删除临时副本并撤销授权。仪器测试覆盖 provider 非导出/目录隔离/单文件流 flag/返回撤销与删除/名称转义/残留清理；真实第三方分享目标往返、跨应用撤销可见性与分享中进程被杀尚未验证。
- 摘要按 A4 分页；系统字体 200%、TalkBack、深色与旋转下的排版未验证（资料/长表单的极端配置矩阵已另行通过，分享与摘要排版仍保留）。
- PDF 预览前会校验文件完整性（≥32 字节、`%PDF-` 头、尾部 4096 字节含 `%%EOF`）；结构不完整（截断/伪装）的文件会提示无法预览——这是为规避低版本平台 pdfium 打开损坏文件后拒绝同进程后续所有 PDF 的进程级缺陷，完整 PDF 不受影响。

## 4. 通知与提醒

- 未授权精确闹钟时自动降级为非精确提醒，触发时间可能有偏差。
- 厂商后台限制（自启动、省电策略）可能导致提醒延迟或不触发；未在厂商设备上验证。
- 锁屏通知默认隐藏具体内容。

## 5. 平台与设备

- 最低支持 Android 8.0（API26）；已在 API26 模拟器（Android 8.0.0 / x86_64）完成全量仪器测试（292 项 0 失败，42 项前置条件跳过）；**未在 API26 真机与厂商 ROM 上运行**。
- 已在 API34 与 API36（含 16 KiB 页）模拟器验证；**未在真机安装或长时间使用**。
- 低内存设备、系统字体 200%、TalkBack、深色模式、屏幕旋转、权限被拒绝后的恢复路径未验证（系统字体 200%+深色+横屏的**资料/长表单**子集已通过，其余页面矩阵进行中）。
- 进程突然终止（`am force-stop`=ActivityManager SIGKILL）后的应用锁状态、草稿与待重传标记恢复已在模拟器验证；真断电/内核崩溃、真实低内存 LMK 与厂商后台限制、系统认证失败→冷却完整往返未验证。
- 应用降级不等于数据格式降级：旧版本无法读取新 schema 时不要强行回退，请通过兼容版本恢复升级前备份。
