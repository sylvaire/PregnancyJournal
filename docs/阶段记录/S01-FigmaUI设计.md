## 设计决策

- 暖白背景、柔和绿色主色、少量暖杏色，中文字体使用 Noto Sans SC。
- 手机基准画板 412 × 915，使用可编辑文字、矢量与自动布局。
- 首版以浅色核心流程为主，深色模式及未覆盖状态需明确标记范围。
- 示例数据为虚构演示内容，不导入用户个人健康信息。

## 首轮交付清单

| 分组 | 界面 |
|---|---|
| 开始与日常 | 欢迎、创建孕期档案、首页、产检列表 |
| 产检与资料 | 产检详情、新建预约、资料列表、资料详情 |
| 用药与健康 | 用药记录、用药方案、健康趋势、孕期时间线 |
| 安全与备份 | 我的、备份状态、恢复预览、备份失败 |
| 关键状态 | 资料空状态、文件导入进度、坚果云连接、恢复密钥 |

- 共 20 个 412 × 915 手机画板，中文使用 Noto Sans SC。
- 建立 11 个品牌语义色、7 个间距、3 个圆角 token 和 6 个文字样式；颜色关联基础色。
- 基础组件含 Material 3 按钮封装（主操作/次操作/禁用）、输入框封装、记录行。
- 连接 63 条显式跨页面跳转，设“首次使用”“日常记录”“备份与恢复”三个起点。工具遍历中包含继承/嵌套反应的数量不作为独立业务连线数量。
- 这些跳转仅演示页面关系，未模拟真实上传、保存、恢复或服药提交；无行为的按钮保留为设计展示，不表示功能可用。
