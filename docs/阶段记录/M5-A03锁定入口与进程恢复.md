## 决策与变更

- **kill 语义**：`adb shell kill -9` 因 shell uid 权限被拒；回退 `am force-stop`（ActivityManager → `Process.killProcess()` → SIGKILL，无生命周期回调）。该语义证明「进程突然终止」下的持久化一致，不证明掉电/页缓存丢失语义；不在模拟器上找 root。
- **不新增依赖**：androidTest 无 UiAutomator，且任务边界禁止改 gradle 配置；改用平台 `UiAutomation`（`androidx.test` 已持有）读取活动窗口并可点击找到的节点，保持零新依赖。
- **测试缺陷修复（非产品缺陷）**：`UiProbe.clickText` 首轮只在文本节点派发 `ACTION_CLICK`，Compose 可点击动作用在祖先节点；改为向上找 `isClickable` 祖先，重跑 8/8。`saveDraft` 首轮误用 `journalEntry` feature 但缺 `pregnancyId` payload，改为先 `savePregnancy` 再对 `pregnancy` feature 存草稿，符合仓库既有约束。
