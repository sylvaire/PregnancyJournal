## 决策与变更

- 采用一个唯一工作名 + 替换语义表达“合并触发”，不按字段或附件派生任务链；运行中的并发由协调器互斥与 Worker 运行标记双重拦截。
- 主设备只是一个协调信号而非协议锁：快照仍按 writerId 分支保全，跨设备不覆盖已有有效提交。
- 自动备份默认关闭、恢复后默认非主设备，避免擅自替他机写入；清除阻断只能由显式“设为主设备”触发。
- 退避有上限且持久化，避免失败后热循环；达到阈值后停止自动重试并要求人工介入，不静默放弃。
- 待备份以 capturedSequence 比较，避免无变化时反复上传；失败不更新最后成功值。
