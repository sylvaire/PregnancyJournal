# M1 基础档案与产检开发

- 开始日期：2026-10-18。
- 状态：首个可运行增量已通过构建、核心自动测试与基础操作验证；M1完整验收未完成。
- 任务：A01–A05、B01–B03 中可独立验证的部分。
- 前置：[M0 技术验证](M0-技术验证与工程启动.md)。P0 全部门槛尚未通过；此阶段不标记生产可用。

## 本轮范围

在构建与安全验证进行期间，编写可独立审查的基础档案、孕周计算和预约业务。主界面以精修稿的欢迎、建档与首页为视觉来源，并读取真实本地数据库，不填入虚构医疗记录。

## 已实现

- Hilt Application / Activity / ViewModel、Flow 状态、Navigation 3 路由。
- 品牌色、主次按钮、记录行与 Figma 原始 SVG 资产。
- 建档、编辑、切换、结束、日期修订历史。
- 孕周计算、预约创建/编辑/完成、产检列表及详情。
- 加密草稿持久化；系统保存状态中只放档案ID和路由。
- 业务变更与 change_log 同一数据库事务。

## 本开发版的明确限制

当前仅开放“今天 / 产检 / 我的”三个已接入真实数据的入口。检查资料/用药/健康的正式入口随相应模块接入，不放置假数据或用静态成功页代替功能。V1.0 最终仍按四入口方案实现。

备份、安全解锁、提醒与完整业务模型尚未接入界面；P0 的快照编解码仅用于技术测试，不提供给用户作为正式备份。

## 接续与验收

2026-10-18已完成开发包编译、12项单元测试、2项加密数据库设备测试及静态检查。模拟器实际操作：空档案→建档→首页；预约输入→离开→重启→草稿恢复；保存预约→重启→详情；完成就诊→产检列表显示“已完成”。测试只用虚构名称。[证据索引](../verification/2026-10-18/README.md)。

## 本轮修正

- 读取表单完成前展示加载，禁止保存上一份表单；草稿切换先保留当前快照，序列化落盘，返回与进入后台及时保存。
- 已保存的业务记录与清除草稿在同一事务；日期变更新增历史依据，不追改已存在预约的孕周快照。
- 欢迎页仅介绍当前已实现的档案/产检能力；正式备份入口尚未开放。
- 编辑档案使用“保存修改”；详情返回使用“返回”；首页安排改为“产检安排”，避免把将来预约误称今日事项。
- 最终截图发现默认紫色导航选中底色，已统一为品牌浅绿；图标按选中/未选中状态着色，深色模式跟随主题前景色。
