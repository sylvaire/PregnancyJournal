## 目标

建立可构建的原生 Android 工程，验证加密数据库、文件、恢复密钥、快照和网络协议；以真实编译与测试证据决定依赖组合。

## 当前进展

- 创建单 `:app` 工程、版本目录和清晰的开发版版本号 `0.1.0-dev`。
- 已发现本机 Gradle 8.13、JDK 23、Android SDK 及多个系统镜像。
- 已查阅 Room 3、Navigation 3 官方发布记录与 SQLCipher Room 3 集成示例；版本目录中的开发基线已通过编译、单元与加密库设备测试。
- 默认网络沙箱无法访问依赖仓库；授权范围内升级网络执行后，官方制品端点返回200。
- 已生成0.1.0-dev APK；12项单元测试、2项API34设备数据库测试通过；lint为0错误、14条依赖更新提示。真实坚果云账号尚未验证。
