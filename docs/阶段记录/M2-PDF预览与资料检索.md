## 决策与变更

- PDF使用系统PdfRenderer，仅渲染当前页，单页位图限制400万像素；不执行文档脚本或访问远程链接。
- 搜索限定当前产检的资料名称，不宣称PDF全文或图片文字识别。
- 新增分类字段使用数据库自动迁移，旧资料默认“其他”。
- 分类为超声、检验、筛查、处方、病历、其他；排序为最近导入、最早导入、名称顺序。同一时间/名称按ID稳定排序。
- PDF采用双击或按钮放大（1至4倍）、滚动查看，图片继续保留既有双指缩放。跳页和当前放大状态可在后台恢复后保留，翻页则复位。
- 打开预览前清除搜索输入焦点并收起键盘，避免遮住资料。
